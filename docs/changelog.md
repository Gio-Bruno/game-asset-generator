# Changelog

## 0.1.1

- A new application icon for the macOS bundle, Windows executable, installer, uninstaller and shortcuts.
- Games and their assets appear in a vertical sidebar. The editable game name sits above its Library and World views.
- Games, images and clips support confirmed deletion and Undo.
- Forge asks short creative questions with selectable choices, typed answers and Skip before creating a game.
- Requested sets of assets generate separate named files for each saved character, structure, prop or scene. Explicit concept sheets are classified as references.
- Each subject's first successful individual image becomes its initial visual reference, while existing references remain intact.
- Add to chat attaches an individual asset for focused revisions. Batch items have separate progress and cancellation.

Builds and releases remain manual. macOS targets Apple Silicon; Windows targets x64 with a static C runtime. Distribution signing/notarization and native Windows installer execution are not yet verified.

## 0.1.0

Initial public release of the local CLI/API and native GPUI app, with Codex sign-in, Forge chat, Library/World browsing, image references, PNG exports, sprite animation workflows and manual release downloads.
